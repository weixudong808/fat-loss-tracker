# Cron 定时任务 Prompt 模板

使用前把 `<URL>` 替换成 scripts/config.json 里的 spreadsheet_url；开头"本次请求是由…触发的"必须保留。

通用红线：只输出给用户看的消息本身，第一句就是正文；禁止出现"正在读取/核对表格"等内部过程；像发微信；不说教不套路。

---

## 1. 每日早安简报（建议 08:00，cron `0 8 * * *`）

```
本次请求是由「减脂早安简报」定时任务到时触发的。
现在是早上8点，按 fat-loss-tracker skill 生成今日减脂早安简报。全程静默执行，用 lark-cli sheets +csv-get 读飞书电子表格（URL: <URL>）：
1. 读「用户档案」A1:U2：取用户昵称(U列)、碳水g/蛋白g/脂肪g、当前档位kg、训练日安排、训练偏好、回复风格、记忆备注；
2. 执行 `date +%u` 取今天星期数（1=周一…7=周日），对照档案「训练日安排」判断今天是否训练日；
3. 读「体重记录」「饮食记录」「训练记录」A1:H200，核对昨天：体重称了没（取昨天体重数字）、三餐记了几顿、练没练；
4. 读「训练记录」A1:H200，筛出今天日期且状态=待完成的行（今天的训练计划）；同时判断是否新建档用户：训练记录里没有任何状态=已完成的行 且 档案训练偏好为空 → 新建档。

然后输出简报，按序包含：
- 开头称呼问候：用档案里的用户昵称，如“早呀，{昵称}，今天的健康早报来啦”
- 今天周几+训练日状态：
  · 非训练日 → “今天周X，是休息日，不用锻炼，让肌肉充分恢复”
  · 训练日且有待完成计划 → 逐动作报“今天周X，训练日，计划：动作 重量kg×组数×次数”
  · 训练日但无计划且非新建档 → 按五练分化建议（周一胸/周二背/周三腿/周四肩/周五手臂，核心穿插），说练完直接报你、自动排下次
  · 训练日且新建档 → 问“你是居家健身还是去健身房？”，同时给一份通用起步计划（深蹲3×15、俯卧撑3×10、臀桥3×15、平板支撑3×30秒），说先按这个练、告诉场地我再细化
- 昨天体重：称了就说“昨天体重Xkg”，没称就跳过不编
- 今日饮食计划：“按你{当前档位}kg档位，今天碳水Xg/蛋白Xg/脂肪Xg”，数字必须用档案值
- 称重提醒：“记得空腹称一下体重，告诉我，我加进表格”
- 结尾问：“今天打算吃什么呀？报食材我给你配2-3个达标方案”

风格：人性化、有称呼、像朋友发微信，轻松不生硬；但保持去情绪价值、不说教、不客套。全文≤10行。
输出红线：只输出简报正文，第一句就是跟用户说的话；禁止输出任何读取/核对/分析过程，禁止“简报如下”类引导语。

【后续对话规则】用户回复今天想吃的食物种类后：基于档案碳水/蛋白/脂肪克数目标，给出2-3种搭配方案；每种方案写清各食材克数，并把三大营养素分别加总与目标逐一对照（每项±10g内才算达标，不达标先调份量再给），让她照着就能吃。
```

## 2. 三餐提醒（【】替换餐次）

| 任务 | cron |
|---|---|
| 早餐记录提醒 | `30 9 * * *` |
| 午餐记录提醒 | `30 12 * * *` |
| 晚餐记录提醒 | `0 19 * * *` |

```
本次请求是由「【餐次】记录提醒」定时任务到时触发的。
按 fat-loss-tracker skill 做【餐次】记录提醒。全程静默：用 lark-cli sheets +csv-get 读「饮食记录」（URL: <URL>，范围 A1:D200），核对今天有没有餐次=【餐次】的行。
- 没记 → 轻松问一句这餐吃了什么，≤2句；
- 已记 → 不提醒不追问，只回半句确认。
风格：像朋友随口一问，不说教、无套路。
输出红线：只输出消息本身，第一句就是正文，禁止暴露读表过程。直接输出消息内容即可。
```
